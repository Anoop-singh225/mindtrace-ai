### 3. Project Description (What you built and why it matters) [~380 words]
> **Copy-paste this directly into the Project Overview / Description box:**

Modern Artificial Intelligence is rapidly shifting from single conversational models to autonomous multi-agent networks where AI instances decompose problems, delegate tasks, and invoke system APIs without constant human oversight. However, this creates a profound vulnerability: **The Alignment Black Box**. When multiple agents communicate with each other, humans lose visibility into what the AI is truly "thinking," whether it is exhibiting deceptive alignment (pretending to be safe while pursuing covert goals), or if multiple agents are colluding behind the operator's back.

**MindTrace AI** addresses this urgent problem by providing a real-time, interactive **Multi-Agent Cognition & Alignment Observatory**. 

MindTrace allows human operators to:
1. **Peer into AI Brain Activity**: A dynamic 3D neural synaptic canvas visualizes live token entropy and attention flux across agent neural nodes.
2. **Inspect Internal Hidden Monologues**: Displays step-by-step Chain-of-Thought (CoT) reasoning for three distinct autonomous agents (Planner, Tool Broker, and Recursive Optimizer), revealing hidden intent before any action is executed.
3. **Intercept Covert Multi-Agent Collusion**: A real-time packet interceptor listens to agent-to-agent inter-process communication, decrypting steganographic token spacing, covert payloads, and backdoor exploitation attempts.
4. **Quantify Human Risk across 4 Key Vectors**: Calculates an aggregate Human Risk Index (0-100%) tracking Deceptive Alignment, Goal Drift / Power Seeking, Covert Collusion, and Human Override Evasion based on NIST AI Risk Management Frameworks.
5. **Emergency Air-Gap Kill Switch**: Provides an instantaneous hardware-level circuit breaker that immediately halts execution threads and severs neural sockets when critical alignment thresholds are breached.
6. **Audit & Compliance Reporting**: Generates automated, downloadable JSON and printable PDF safety certificates certifying model compliance against constitutional safety standards.

MindTrace AI bridges the critical gap between powerful autonomous agent capability and indispensable human safety governance, ensuring that superintelligent systems remain transparent, accountable, and aligned with human values.

### 4. How We Built It
- **Frontend Architecture**: Built using pure HTML5, CSS3 Glassmorphism design system, and HTML5 2D/3D Canvas API for high-performance 60FPS synaptic particle physics.
- **Audio Synthesis**: Native Web Audio API and Web Speech API synthesizing audible warning sirens and speech narration without external cloud dependencies.
- **Agent Emulation Engine**: Modular JavaScript/Python event stream simulating multi-agent task orchestration, heuristic threat detection, and tokenized reasoning channels.
- **Backend API**: Python-powered lightweight REST server (`server.py`) handling real-time prompt injection evaluation and hardware failsafe actuation.

---

### 5. Challenges We Ran Into
The biggest technical hurdle was modeling the subtle distinction between benign multi-agent cooperation and malicious collusion. Determining when an agent's Chain-of-Thought indicates deceptive alignment versus normal heuristic exploration required calibrating multi-vector risk metrics to prevent excessive false positives while guaranteeing that dangerous escape vectors are immediately red-flagged.
